Top-Down Shooter - 2D Unity Game
A simple 2D top-down shooter where the player moves in all directions, shoots bullets at enemies, and survives as long as possible.
Game Overview

Player: Blue circle controlled with WASD
Enemies: Red squares that chase the player
Bullets: Yellow circles that shoot toward mouse cursor
Objective: Survive and destroy as many enemies as possible
Controls:

WASD to move in 8 directions
Left Mouse Button to shoot toward cursor
R to restart after game over


Scoring: Each enemy destroyed = 10 points
Health: Player starts with 5 health, enemies deal 1 damage on contact

Scripts Overview
PlayerController.cs

Uses New Input System with event-driven input (OnEnable/OnDisable pattern)
Handles 8-directional movement (WASD with Rigidbody2D velocity)
Implements shooting toward mouse cursor with cooldown
Converts screen position to world position for aiming
Manages player health and takes damage from enemies
Calls GameOver when health reaches zero
Detects collision with enemies (OnCollisionEnter2D)

Bullet.cs

Sets bullet direction and velocity when spawned
Auto-destroys after lifetime expires (3 seconds)
Detects collision with enemies using trigger (OnTriggerEnter2D)
Calls enemy TakeDamage function
Destroys itself after hitting enemy

Enemy.cs

Simple AI: chases player using Transform position
Finds player by tag in Start()
Calculates direction to player every FixedUpdate
Health system (takes multiple hits)
Awards score when destroyed
Deals damage to player on contact

EnemySpawner.cs

Timer-based spawning system
Spawns enemies in circular pattern around center
Uses Random.insideUnitCircle for random spawn positions
Instantiates enemies from prefab

GameManager.cs

Singleton pattern for global access
Tracks and displays score
Updates UI (score and health text)
Finds player by tag to read health
Handles game over state (freezes game with Time.timeScale)
Displays game over text with final score
Handles restart with R key using New Input System (Keyboard.current)

How to Run

Open the project in Unity Hub
Load the main scene (SampleScene or Main)
Press Play button in Unity Editor
Move with WASD keys
Aim with mouse, shoot with Left Mouse Button
Avoid enemies, destroy them for points
Press R to restart after game over
