Brick Breaker - 2D Unity Game
A classic 2D brick breaker game where the player controls a paddle to bounce a ball and destroy bricks.
Game Overview

Paddle: Green horizontal bar controlled by the player
Ball: White circle that bounces around the screen
Bricks: Orange rectangles arranged in a grid at the top
Objective: Destroy all bricks without losing all lives
Controls:

Arrow Keys (Left/Right) to move paddle
R to restart after game over or win


Scoring: Each brick destroyed = 10 points
Lives: Start with 3 lives, lose one when ball falls off screen

Scripts Overview
PaddleMovement.cs

Controls paddle movement (left/right with arrow keys)
Horizontal input handling

BallMovement.cs

Launches ball at game start in random diagonal direction
Handles ball reset after falling
Uses Invoke to delay relaunch by 1 second

Brick.cs

Detects collision with ball
Awards points to GameManager
Destroys brick when hit

BrickManager.cs

Spawns grid of bricks at game start
Uses nested for loops to create rows and columns
Calculates brick positions with spacing

DeathZone.cs

Trigger zone below paddle
Detects when ball falls off screen
Triggers life loss and ball reset

GameManager.cs

Singleton pattern for global access
Tracks score and lives
Updates UI displays
Checks win condition (all bricks destroyed)
Checks lose condition (lives = 0)
Handles game restart (R key)

How to Run

Open the project in Unity Hub
Load the main scene (SampleScene or Main)
Press Play button in Unity Editor
Use Arrow Keys to move paddle
Destroy all bricks to win
Press R to restart after game over or win
